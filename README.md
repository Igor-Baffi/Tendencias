# Modelo 5W para Análise de Tendências em Ciência da Computação

## Objetivo
Estruturar a análise de tendências em Ciência da Computação seguindo o método **5W** (What, Why, Who, When, Where) + impactos e aplicações práticas.

---

## Estrutura de Diretórios

Cada tendência deve ocupar um diretório com a seguinte organização:

```
tendencia-[nome-em-kebab-case]/
  ├── README.md              # Visão geral e navegação
  ├── 1-what.md              # O que é?
  ├── 2-why.md               # Por que é importante?
  ├── 3-who.md               # Quem está desenvolvendo?
  ├── 4-when.md              # Quando começou? Quando vai crescer?
  ├── 5-where.md             # Onde está sendo aplicada?
  ├── aplicacoes.md          # Casos práticos e exemplos
  ├── impacto.md             # Impactos: mercado, sociedade, educação
  └── referencias.md         # Fontes, artigos, links
```

---

## Conteúdo de Cada Seção

### **1. README.md**
- Título da tendência
- Uma frase resumida
- Links para as 5 seções do modelo
- Última atualização
- Contribuidor

### **2. 1-what.md (O que é?)**
- Definição clara e objetiva
- Contexto histórico sucinto
- Conceitos-chave
- Como funciona (resumido)
- Diferenças de abordagens/tecnologias similares

### **3. 2-why.md (Por que é importante?)**
- Problema que resolve
- Benefícios principais
- Impacto esperado
- Porque os profissionais devem saber disso
- Tendências anteriores que levaram a esta

### **4. 3-who.md (Quem está desenvolvendo?)**
- Empresas líderes
- Pesquisadores/Instituições
- Comunidades open-source
- Startups inovadoras
- Investimento/Funding

### **5. 4-when.md (Quando começou? Quando vai crescer?)**
- Marcos históricos
- Estágio atual de maturidade
- Previsões de adoção
- Ciclo de vida da tendência
- Próximos marcos esperados

### **6. 5-where.md (Onde está sendo aplicada?)**
- Setores/indústrias principais
- Casos de uso em diferentes domínios
- Geografia: regiões/países líderes
- Ambientes: cloud, on-premise, edge, etc.

### **7. aplicacoes.md (Casos Práticos)**
- Exemplo 1: Descrição + como foi implementado
- Exemplo 2: Diferente segmento/contexto
- Exemplo 3: Inovação/caso de sucesso
- Exemplos de falhas/aprendizados

Formato sugerido:
```markdown
## Aplicação: [Nome do caso]
- **Contexto:** [Onde/quando foi aplicado]
- **Desafio:** [Problema que existia]
- **Solução:** [Como a tendência foi usada]
- **Resultado:** [Impacto mensurável]
- **Lições aprendidas:** [O que se pode aprender]
```

### **8. impacto.md (Impactos)**
- **Impacto técnico:** Como muda a forma de desenvolver
- **Impacto no mercado:** Novas profissões, demanda de skills
- **Impacto social:** Benefícios e riscos para a sociedade
- **Impacto educacional:** O que as universidades devem ensinar
- **Impacto ambiental:** Sustentabilidade, consumo de energia, etc.

### **9. referencias.md (Referências)**
- Artigos científicos
- White papers
- Documentação oficial
- Cursos e tutoriais
- Podcasts/Vídeos
- Livros

Formato:
```markdown
### [Título do recurso]
- **Tipo:** [Artigo/Vídeo/Curso/Livro]
- **Autor/Fonte:** [Nome]
- **Data:** [Quando foi publicado]
- **Link:** [URL]
- **Resumo:** [Uma frase sobre o conteúdo]
```

---

## Convenções

### Nomes de Diretórios
- Use kebab-case: `tendencia-inteligencia-artificial-generativa`
- Evite caracteres especiais
- Seja descritivo mas conciso

### Markdown
- Use títulos hierárquicos (H1 > H2 > H3...)
- Adicione índices/sumários nas páginas maiores
- Inclua links internos entre seções relacionadas
- Mantenha parágrafos concisos e informativos

### Datas
- Use formato ISO: `YYYY-MM-DD`
- Atualize sempre que adicionar informação

### Links
- Use URLs completas com protocolo
- Verifique se links não estão quebrados
- Prefira recursos em português quando disponível, mas inclua versões em inglês também

## Exemplo de Uso

Para adicionar uma nova tendência:

1. Crie um diretório: `tendencia-[nome]`
2. Crie os 9 arquivos usando os templates abaixo
3. Preencha cada seção seguindo as instruções
4. Atualize o README principal do repositório

- [ ] impacto.md completo

- [ ] Links internos funcionando
- [ ] Formatação consistente
- [ ] Data de criação/atualização registrada
